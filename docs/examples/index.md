# Magnifx Examples

Live demos showcasing Magnifx features. Each example includes the full HTML source code.

## Available Examples

### [Basic Usage](./basic-usage.html)
Demonstrates single image zoom, synced groups with hover mode, and click-to-toggle mode.

**Features shown:**
- Synced group (hover mode)
- Synced group (click mode)  
- Single image with custom options

### [Click to Zoom](./click-to-zoom.html)
Example focusing on click-to-toggle interaction for detailed image analysis.

### [Sync Gallery](./sync-gallery.html)
Advanced example showing multiple synchronized images for comparison.

## Running Examples Locally

To run these examples locally:

1. Clone the repository
2. Open the HTML files in your browser
3. Ensure `magnifx.js` is accessible from the examples folder

```bash
git clone https://github.com/AndreaGelmini/magnifx.git
cd magnifx/docs/examples
# Open any .html file in your browser
```
